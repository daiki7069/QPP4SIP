================================================================================

ベースモデル: BERT
分析対象: FP
有意水準: p < 0.05
効果量閾値: |Cohen's d| > 0.2

================================================================================

ルール 1: WIG
--------------------------------------------------------------------------------
  条件: WIG が 1.1640 より 低い
  かつ BERTが clarification と予測
  → QPPを使って answer 側に補正すべき

  統計情報:
    - Cohen's d: -0.0842
    - p値: 0.012631
    - 誤分類グループの中央値: 1.1640
    - 正解グループの中央値: 1.1887

ルール 2: SClarity
--------------------------------------------------------------------------------
  条件: SClarity が 7.9151 より 低い
  かつ BERTが clarification と予測
  → QPPを使って answer 側に補正すべき

  統計情報:
    - Cohen's d: -0.0428
    - p値: 0.085178
    - 誤分類グループの中央値: 7.9151
    - 正解グループの中央値: 8.0917

ルール 3: Clarity
--------------------------------------------------------------------------------
  条件: Clarity が 1.5989 より 低い
  かつ BERTが clarification と予測
  → QPPを使って answer 側に補正すべき

  統計情報:
    - Cohen's d: -0.0301
    - p値: 0.099243
    - 誤分類グループの中央値: 1.5989
    - 正解グループの中央値: 1.6409


================================================================================
Pythonコード形式の判定関数
================================================================================

def should_use_qpp_correction(qpp_features, bert_prediction):
    """
    BERTの予測をQPPで補正すべきかどうかを判定
    
    Args:
        qpp_features: dict, QPP特徴量の辞書
        bert_prediction: str, BERTの予測 ('clarification' または 'answer')
    
    Returns:
        tuple: (should_correct: bool, correction_direction: str or None)
    """
    
    # ルール 1: WIG
    if qpp_features.get('WIG', float('inf')) < 1.1640 and bert_prediction == 'clarification':
        return True, 'answer'
    
    # ルール 2: SClarity
    if qpp_features.get('SClarity', float('inf')) < 7.9151 and bert_prediction == 'clarification':
        return True, 'answer'
    
    # ルール 3: Clarity
    if qpp_features.get('Clarity', float('inf')) < 1.5989 and bert_prediction == 'clarification':
        return True, 'answer'
    
    return False, None  # QPP補正不要
