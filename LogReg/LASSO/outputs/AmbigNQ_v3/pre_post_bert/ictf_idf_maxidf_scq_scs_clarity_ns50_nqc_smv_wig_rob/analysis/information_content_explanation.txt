================================================================================
「情報量が少ない」とは？ - IDF/ICTFの意味と解釈
================================================================================

【IDF (Inverse Document Frequency) の定義】
IDF(t) = log(N / Nt)

- N: コレクション全体の文書数
- Nt: 語tを含む文書数
- AvgIDF: クエリに含まれる各語のIDFの平均
- MaxIDF: クエリに含まれる語のIDFの最大値

【ICTF (Inverse Collection Term Frequency) の定義】
ICTF(t) = log(|D| / tf(t, D))

- |D|: コレクション全体の総語数
- tf(t, D): 語tのコレクション全体での出現回数
- AvgICTF: クエリに含まれる各語のICTFの平均

================================================================================
【「情報量が少ない」の意味】
================================================================================

「情報量が少ない」= IDF/ICTFが低い = クエリに含まれる語が一般的で頻繁に出現する

具体例：

【情報量が少ないクエリ（IDF/ICTFが低い）】
- "what is the meaning of"
  → "what", "is", "the", "of" など、多くの文書に出現する一般的な語
  → AvgIDF/AvgICTFが低い
  → クエリの意図が曖昧で、検索が難しい

- "how do you"
  → 非常に一般的な語のみ
  → 情報量が少ない

【情報量が多いクエリ（IDF/ICTFが高い）】
- "quantum computing algorithm"
  → "quantum", "computing", "algorithm" など、特定のトピックに関連する珍しい語
  → AvgIDF/AvgICTFが高い
  → クエリの意図が明確で、検索が容易

- "machine learning neural network"
  → 専門的な語が含まれる
  → 情報量が多い

================================================================================
【なぜ「情報量が少ない」と表現するのか】
================================================================================

1. 情報理論的な観点
   - 珍しい語（IDF/ICTFが高い）→ 情報エントロピーが高い → 情報量が多い
   - 一般的な語（IDF/ICTFが低い）→ 情報エントロピーが低い → 情報量が少ない

2. 検索の観点
   - 一般的な語が多いクエリ → 多くの文書とマッチする可能性が高い
   → 検索結果が広範囲にわたる → クエリの意図が不明確
   - 珍しい語が多いクエリ → 特定の文書とマッチする可能性が高い
   → 検索結果が絞り込まれる → クエリの意図が明確

3. 実用的な意味
   - 情報量が少ない = クエリが一般的すぎて、特定の情報を探しにくい
   - 情報量が多い = クエリが具体的で、特定の情報を探しやすい

================================================================================
【分析結果との関係】
================================================================================

【発見】情報量が少ない（AvgIDF/AvgICTF/MaxIDFが低い）クエリで、
        QPP統合が特に効果的

解釈：
1. RoBERTaは一般的な語が多いクエリ（情報量が少ない）で弱い
   - 文脈情報が少なく、BERTの事前学習知識だけでは判断が難しい

2. QPPは検索結果の質を評価することで補完できる
   - 情報量が少ないクエリでも、検索結果の質（Clarity、WIGなど）を
     評価することで、クエリの難易度や意図を推測できる

3. 特にClarityが高い場合、QPP統合が効果的
   - 情報量が少ないが、明確度が高いクエリ
   - → 検索結果が一貫している（Clarityが高い）
   - → QPPがこの一貫性を活用して、RoBERTaの判断を補強できる

================================================================================
【具体例で理解する】
================================================================================

例1: 情報量が少ないクエリ
- クエリ: "what is the"
- AvgIDF: 低い（"what", "is", "the"は一般的な語）
- AvgICTF: 低い
- → RoBERTaは判断が難しい（文脈が少ない）
- → QPP統合が効果的（検索結果の質で判断を補強）

例2: 情報量が多いクエリ
- クエリ: "quantum computing algorithm"
- AvgIDF: 高い（"quantum", "computing", "algorithm"は珍しい語）
- AvgICTF: 高い
- → RoBERTaは判断しやすい（文脈が豊富）
- → QPP統合の効果は限定的

================================================================================
【まとめ】
================================================================================

「情報量が少ない」= クエリに含まれる語が一般的で頻繁に出現する
  → IDF/ICTFが低い
  → クエリの意図が曖昧で、検索が難しい
  → RoBERTaは弱いが、QPP統合が効果的

「情報量が多い」= クエリに含まれる語が珍しく、特定のトピックに関連
  → IDF/ICTFが高い
  → クエリの意図が明確で、検索が容易
  → RoBERTaは強いが、QPP統合の効果は限定的
