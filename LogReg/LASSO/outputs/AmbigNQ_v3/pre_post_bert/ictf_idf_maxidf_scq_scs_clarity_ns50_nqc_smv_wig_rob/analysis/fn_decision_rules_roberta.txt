================================================================================
QPPを使うべき場面の判定ルール (FN分析)
================================================================================

ベースモデル: RoBERTa
分析対象: FN
有意水準: p < 0.05
効果量閾値: |Cohen's d| > 0.2

================================================================================

ルール 1: AvgIDF
--------------------------------------------------------------------------------
  条件: AvgIDF が 5.9571 より 高い
  かつ RoBERTaが answer と予測
  → QPPを使って answer 側に補正すべき

  統計情報:
    - Cohen's d: 0.1044
    - p値: 0.000015
    - 誤分類グループの中央値: 5.9571
    - 正解グループの中央値: 5.6261

ルール 2: SClarity
--------------------------------------------------------------------------------
  条件: SClarity が 8.5071 より 高い
  かつ RoBERTaが answer と予測
  → QPPを使って answer 側に補正すべき

  統計情報:
    - Cohen's d: 0.1026
    - p値: 0.000017
    - 誤分類グループの中央値: 8.5071
    - 正解グループの中央値: 8.0972


================================================================================
Pythonコード形式の判定関数
================================================================================

def should_use_qpp_correction(qpp_features, bert_prediction):
    """
    RoBERTaの予測をQPPで補正すべきかどうかを判定
    
    Args:
        qpp_features: dict, QPP特徴量の辞書
        bert_prediction: str, RoBERTaの予測 ('clarification' または 'answer')
    
    Returns:
        tuple: (should_correct: bool, correction_direction: str or None)
    """
    
    # ルール 1: AvgIDF
    if qpp_features.get('AvgIDF', float('-inf')) > 5.9571 and bert_prediction == 'answer':
        return True, 'answer'
    
    # ルール 2: SClarity
    if qpp_features.get('SClarity', float('-inf')) > 8.5071 and bert_prediction == 'answer':
        return True, 'answer'
    
    return False, None  # QPP補正不要
