================================================================================
RoBERTaが弱い部分の共通特徴とQPP統合が効果的なケースの分析結果
================================================================================

【分析概要】
- 弱いケース（全体）: 679件（RoBERTaが誤分類したケース）
- 弱い + QPP統合が効果的: 105件（改善量 >= 0.01）
- 弱い + QPP統合が効果的でない: 574件

================================================================================
【発見1: RoBERTaが弱いときの共通特徴】
================================================================================

統計的に有意な特徴は見つかりませんでした（p < 0.05の特徴なし）。

→ これは重要な発見：
  - RoBERTaが弱いケースは多様で、単一のQPP特徴量では説明できない
  - 複数のQPP特徴量の組み合わせや、他の要因（クエリの複雑さ、文脈など）が
    影響している可能性がある
  - クラスタリング分析でパターンを探索する必要がある

================================================================================
【発見2: QPP統合が効果的なケースの共通特徴】
================================================================================

以下の4つの特徴量で、QPP統合が効果的なケースと効果的でないケースに
統計的に有意な差が見つかりました：

1. AvgIDF（平均IDF）
   - 効果的: 5.40 vs 効果的でない: 5.87（-8.0%低い）
   - p=0.011, Cohen's d=-0.291（中程度の効果量）
   - → AvgIDFが低い時、QPP統合が効果的

2. AvgICTF（平均ICTF）
   - 効果的: 9.68 vs 効果的でない: 10.14（-4.5%低い）
   - p=0.023, Cohen's d=-0.264（中程度の効果量）
   - → AvgICTFが低い時、QPP統合が効果的

3. Clarity（明確度）
   - 効果的: 1.26 vs 効果的でない: 1.23（+2.5%高い）
   - p=0.010, Cohen's d=0.259（中程度の効果量）
   - → Clarityが高い時、QPP統合が効果的

4. MaxIDF（最大IDF）
   - 効果的: 11.15 vs 効果的でない: 11.97（-6.8%低い）
   - p=0.029, Cohen's d=-0.225（小〜中程度の効果量）
   - → MaxIDFが低い時、QPP統合が効果的

【解釈】
- 情報量が少ないクエリ（AvgIDF/AvgICTF/MaxIDFが低い）で、
  QPP統合が特に効果的
- ただし、Clarityが高い（明確度が高い）場合も効果的
- これは一見矛盾しているが、以下のように解釈できる：
  * 情報量が少ないが、明確度が高いクエリ → QPPが補完情報を提供できる
  * RoBERTaは情報量の少なさに弱いが、QPPは明確度の高さを活用できる

================================================================================
【発見3: クラスタリングによるパターン発見】
================================================================================

弱いケースを3つのクラスタに分類：

【クラスタ0】改善率: 0.11（中程度）
- 特徴: AvgICTF高(11.24), AvgIDF高(6.92), MaxIDF高(14.18), 
        SClarity高(9.46), WIG低(1.88), nSigma低(0.45)
- サンプル数: 283件
- 解釈: 情報量が豊富だが、WIGが低い（検索結果の多様性が低い）

【クラスタ1】改善率: 0.17（高い）
- 特徴: AvgICTF中(10.46), AvgIDF中(6.17), MaxIDF中(13.00),
        SClarity中(8.66), WIG高(3.18), nSigma高(0.79), SMV高(5.64)
- サンプル数: 152件
- 解釈: 中程度の情報量で、WIGとnSigmaが高い（検索結果の多様性・分散が高い）

【クラスタ2】改善率: 0.20（最も高い）
- 特徴: AvgICTF低(8.46), AvgIDF低(4.27), MaxIDF低(8.41),
        SClarity低(6.70), WIG中(2.03), nSigma低(0.49)
- サンプル数: 244件
- 解釈: 情報量が少ないが、QPP統合が最も効果的

================================================================================
【重要な知見のまとめ】
================================================================================

1. RoBERTaが弱いケースは多様
   - 単一のQPP特徴量では説明できない
   - 複数の特徴量の組み合わせや、クラスタリングでパターンが見える

2. QPP統合が効果的なケースの特徴
   - 情報量が少ない（AvgIDF/AvgICTF/MaxIDFが低い）
   - 明確度が高い（Clarityが高い）
   - → 情報量が少ないが明確なクエリで、QPPが特に効果的

3. クラスタリングによる発見
   - クラスタ2（情報量が少ない）で、QPP統合が最も効果的（改善率0.20）
   - クラスタ1（中程度の情報量、WIG/nSigmaが高い）でも効果的（改善率0.17）

4. 実用的な示唆
   - AvgIDF < 5.4 かつ AvgICTF < 9.7 かつ Clarity > 1.26 の時
     → QPP統合が特に効果的（改善率が高い可能性）
   - MaxIDF < 11.2 の時も効果的
